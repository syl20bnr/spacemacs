* Description
This layer adds [[https://github.com/alexluigit/dirvish][dirvish]] support to Spacemacs. Dirvish is a modern, actively
maintained file manager that extends dired with preview windows, async VC info,
and many other features.

Dirvish was designed as a modern replacement for ranger.el, addressing its
maintenance issues while providing better dired integration. Unlike ranger.el
which replaces dired, dirvish extends dired - meaning all your existing dired
knowledge and configurations continue to work.

** Features:
- Multi-pane layout with file previews (async, non-blocking)
- Full dired compatibility - all dired commands work seamlessly
- Async VC/git status information
- TRAMP/remote file support
- Evil/vim-style navigation
- Subtree expansion without leaving dired
- File narrowing/filtering
- Integration with Embark, Magit, wdired, and consult
- Minimal configuration required - works well out of the box

* Install
To use this configuration layer, add it to your =~/.spacemacs=. You will need to
add =dirvish= to the existing =dotspacemacs-configuration-layers= list in this
file.

Make sure that the =ranger= layer is removed or commented out in the
=dotspacemacs-configuration-layers= list. Or add =dirvish= below the =ranger=
layer. Spacemacs uses the layer that's listed last.

* Configuration
** Layer Variables
The following layer variables can be configured:

| Variable                    | Default | Description                                    |
|-----------------------------+---------+------------------------------------------------|
| =dirvish-enable-dired-omit= | =t=     | Enable =dired-omit-mode= by default in dirvish |

Example configuration:

#+BEGIN_SRC emacs-lisp
  (setq-default dotspacemacs-configuration-layers
                '((dirvish :variables
                           dirvish-enable-dired-omit t)))
#+END_SRC

** Dirvish Attributes
This layer automatically adds the appropriate icons attribute (=nerd-icons= or
=all-the-icons=) based on your =dotspacemacs-default-icons-font= setting.

You can customize =dirvish-attributes= in your =dotspacemacs/user-config=:

#+BEGIN_SRC emacs-lisp
  (setq dirvish-attributes
        '(vc-state subtree-state nerd-icons collapse git-msg file-time file-size))
#+END_SRC

Available attributes include: =vc-state=, =subtree-state=, =nerd-icons=,
=all-the-icons=, =collapse=, =git-msg=, =file-time=, =file-size=, and more.
See [[https://github.com/alexluigit/dirvish#attributes][dirvish documentation]] for the full list.

** Mode Line Format
A recommended mode-line format for dirvish (add to =dotspacemacs/user-config=):

#+BEGIN_SRC emacs-lisp
  (setq dirvish-mode-line-format
        '(:left (sort symlink) :right (omit yank index)))
#+END_SRC

This shows:
- Left side: current sort method and symlink indicator
- Right side: omit status, yank status, and current index

This layer does not set this variable to respect =M-x customize= settings.

* Key bindings
** Global

| Key binding   | Description                              |
|---------------+------------------------------------------|
| ~SPC a t r r~ | Open dirvish                             |
| ~SPC a t r d~ | Dirvish DWIM (do what I mean)            |
| ~SPC a t r s~ | Open dirvish-side (sidebar file manager) |
| ~SPC a t r q~ | Open dirvish-quick-access                |
| ~SPC a t r f~ | Open dirvish-fd (find files with fd)     |
| ~SPC j d~     | Jump to dired (uses dirvish when enabled)|
| ~SPC j D~     | Jump to dired in other window            |

Note: The =atr= prefix is shared with the =ranger= layer. When dirvish shadows
ranger, these bindings seamlessly replace ranger's equivalents. The =SPC j d=
and =SPC j D= bindings are provided by spacemacs-defaults and automatically use
dirvish when =dirvish-override-dired-mode= is active.

** Dired Mode
The following keybindings are available in dired buffers when using dirvish:

*** Navigation

| Key binding | Description                                  |
|-------------+----------------------------------------------|
| ~h~         | Go to parent directory                       |
| ~l~         | Open directory in same window, file in other |
| ~gr~        | Refresh buffer                               |

*** Dirvish-specific

| Key binding | Description                 |
|-------------+-----------------------------|
| ~q~         | Quit dirvish                |
| ~/~         | Filter/narrow files         |
| ~TAB~       | Toggle subtree expansion    |
| ~f~         | Toggle preview layout       |
| ~gf~        | Toggle preview layout (alt) |
| ~gt~        | Switch between layouts      |
| ~gd~        | Open dispatch menu          |
| ~gl~        | Change ls switches          |

*** Dired Enhancements

| Key binding | Description               |
|-------------+---------------------------|
| ~i~         | Toggle read-only (wdired) |
| ~I~         | Insert subdirectory       |
| ~g$~        | Hide subdirectory         |
| ~g?~        | Show dired summary        |
| ~gj~        | Next directory line       |
| ~gk~        | Previous directory line   |
| ~gG~        | Change group              |
| ~gO~        | Open in other window      |
| ~C-l~       | Recenter view             |
